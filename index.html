01Protocol-Independent Routing›
Static routesAggregate / GeneratedMartianRIB groupsLoad balancingFBF
Static route → route manuelle ; preference Junos par défaut = 5
Resolve → autorise recursive lookup pour next-hop non directement connecté
Aggregate → résumé basé sur contributing routes ; route active si au moins une contribution existe
Generated → similaire aggregate mais next-hop hérité d’une contributing route
Martian → préfixes considérés invalides/ignorés par défaut
RIB group → copie des routes entre tables, souvent inet.0 ↔ VRF/inet.3 selon design
Load balancing → multipath nécessite policy then load-balance per-packet ; en pratique ECMP hash par flow
FBF → firewall filter qui force un next-hop/routing-instance selon critères trafic

09RSVP-TE›
RSVP LSPCSPFExplicit pathStrict / LooseBandwidthSetup/Hold priorityFRRAdmin-groups
Rôle → créer des LSP avec contraintes : bande passante, chemin explicite, admin-groups, protection
CSPF → calcule chemin en retirant liens qui ne respectent pas contraintes puis SPF

FRR → local repair rapide ; link-protection protège lien ; node-protection protège noeud suivant
